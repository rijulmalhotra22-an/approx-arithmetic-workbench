Scope and honesty statement

This workbench evaluates behavioural (bit-accurate) models of the adders and multipliers, not synthesised netlists. Accuracy metrics (ER, MED, NMED, MRED, bias, max error) are exact for the modelled functions. Hardware figures in the tables are a transparent unit-gate estimate for relative comparison; sign-off numbers must come from synthesis (e.g. the sky130 flow of the WA-SASC paper). Nothing here is presented as a measured silicon result.

Definitions

  • ER error rate = P(result ≠ exact). ED = |approx - exact|. MED = mean ED. NMED = MED / max output. MRED = mean(ED / exact), exact > 0. Bias = mean signed error.
  • Hardware estimate: unit-gate model (AND/OR = 1, XOR = 2, FA = 7 GE, HA = 3 GE); delay in unit gate delays along the critical path. ADP = area × delay.
  • WA-SASC/T width tag t = highest block index holding a set bit in either operand (t = 1 if only block 0 is active); it can be overridden to study a mis-configured tag (data above t is masked, as the hardware would).
